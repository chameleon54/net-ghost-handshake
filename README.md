# Net-Ghost: Handshake

A single-player browser first-person shooter built with three.js.

Work in progress.

## Run it

Needs Node.js 22.12 or newer.

```
npm install
npm run dev
```

Open the address it prints (normally http://localhost:5173).

To check a production build: `npm run build`, then `npm run preview`.
